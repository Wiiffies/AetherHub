Welcome

This site is a pixel-faithful mirror of the in-game UI library (UILIB): 2px chiselled bevels, navy title bar, tab control, group boxes, yellow tooltips and message-box notifications. One loadstring runs everything — the Loader detects which game you are in and executes the right app. Hover anything — the status bar tells you what it does.

Loader — how it works

One loadstring for every game. The Loader checks which game you are in (PlaceId) and executes the right app — no per-game loadstrings, no menus. Unsupported game? It tells you instead of breaking.

Help topics
How do I run it?

Copy the loadstring from the Get Script tab, paste it into your executor and execute. That is the only way — there is no file to download and no key.

It says "no client" / nothing happens?

Attach your executor first, join Steal an Egg, then execute the loadstring. Re-executing is safe — the old hub unloads itself before the new one opens (zoom rectangle and all).

Is it keyless?

Yes. There is no key system in either build. If a download asks you to complete links, it is not us.

Does the site do anything shady?

No. This page is 100% static HTML/CSS/JS. The Copy button only copies text — view source and see.

Setup — 3 steps

Step 1. Press Copy below.
Step 2. Join any supported game, paste into your executor and execute.
Step 3. The Loader detects the game and opens its app. No download, no key, no per-game loadstrings.
